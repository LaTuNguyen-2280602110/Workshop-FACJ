# FCAJ x Agentic AI Build Week Event

## Purpose of the Event

The event was organized as a hands-on Hackathon (Build Week) with the following objectives:
- Encouraging practical experience: Providing participants with an opportunity to design, build, deploy, and present Agentic AI applications on AWS.
- Solving real-world business problems: Inspiring participants to identify business pain points and propose AI-powered technical solutions to address them.
- Networking and learning: Creating an environment where participants could exchange knowledge, strengthen teamwork skills, improve system architecture thinking, and practice presenting projects to judges within a limited time frame.

## List of Presenting Teams
- Team 1: Developed an Agent AI-based system to support business strategists. The project focused on collecting company structure and revenue information from publicly available data.
- Team 2K (Long, Vĩ, Phát, Ấn, Nghĩa): Introduced an AI-powered assistant that helps engineers solve AWS architecture and cost optimization challenges.
- Smart Monitoring Team (Nguyễn Huy, Huỳnh An Khương, Hoàng Hình Đức, Ngô Khôi, Đặng Nguyễn Phước Lộc): Presented a Computer Vision-based monitoring system using YOLO and ByteTrack to track pedestrian movement.
- Six Piller: Proposed an anti-money laundering solution for banks and cryptocurrency exchanges by automating investigation workflows.
## Key Highlights.
- Challenges of legacy architectures: The teams emphasized that traditional systems are often complex, difficult to maintain, and lack the flexibility required to process large-scale data or rapidly changing business requirements.
- Transition to modern architectures: The presentations focused on adopting AWS cloud-native services such as AWS Lambda, Amazon DynamoDB, and AWS Amplify to improve scalability, performance, and cost efficiency.
## Architecture & Tools
- Applied Agentic AI and Large Language Models (LLMs) to automate business workflows.
- Leveraged Amazon Q Developer and other AI-assisted development tools to accelerate coding, troubleshooting, and software development.
- Implemented Event-Driven Architecture using services such as Amazon Kinesis Data Streams for real-time transaction processing.
## What I Learned
- Design Thinking: Learned to focus on users' pain points instead of concentrating solely on technical implementation.
- Technical Architecture: Gained a better understanding of building secure, scalable, and cost-efficient systems using services such as Amazon Cognito and AWS Key Management Service (KMS).
- Modernization Strategy: Learned the importance of migrating from third-party solutions to AWS-native services to improve compliance, maintainability, and operational efficiency.
## Applying the Knowledge
* The concepts of multi-agent systems and real-time data processing can be directly applied to developing tools for Solutions Architects (SAs) or building financial fraud detection systems.
## Event Experience
* Hands-on Technical Experience
- The participating teams experienced an intensive 24-hour hackathon, dealing with real-world challenges such as code conflicts, branch management, debugging, and tight project deadlines.
* Using Modern Development Tools
- Participants utilized AI-powered tools to generate ideas, design system architectures, and accelerate software development.
* Networking and Collaboration
- The hackathon created an excellent opportunity for students from different universities to exchange knowledge, collaborate effectively, and set aside personal differences in order to achieve a common goal.
## Key Takeaway
A great idea has little value if it remains only on paper. The hackathon demonstrated that successful execution, teamwork, and effective project pitching are essential to transforming ideas into practical solutions that create real-world impact.
